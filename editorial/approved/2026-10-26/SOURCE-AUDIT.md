# Source audit / 26 October 2026

## Editorial facts and confidence

**Micron DRAM feature:** Micron's 21 October 2026 slide 16 states it is extending 6F², developing 3D DRAM and not pursuing 4F² because of cost/complexity. This is primary slide content seen through a third-party slide mirror. Micron's 19 October company press release confirms the webinar and presenter. Tom's Hardware reports Scott DeBoer's accompanying explanation about capacitor pitch and approximately two decades of investigation. IBM and Intel primary histories substantiate Dennard and the 1103 chronology. A 2025 IEEE paper documents an actual 4F² integration demonstration; it does not establish high-volume commercial superiority. Do not write '4F² is physically impossible', 'Micron proved all competitors wrong' or '3D DRAM is shipping'. Micron's 1δ timing and density are forward-looking targets.

**Judy Malloy profile:** Her own notes document *Uncle Roger* beginning on The WELL in December 1986, 1987 UNIX shell interactive publication, Apple II BASIC and later web versions. The 1986 keywords were not live web hyperlinks. Pathfinders and the Electronic Literature Directory corroborate the work and chronology. Her personal biography supports 1969 Ball Aerospace catalogue work, card-catalogue art and later editorial projects. The exact Malloy pull quote comes from her 2014 Literary Platform interview; all other pull quote language is Toolglass's. Avoid claiming an uncontested 'first online novel'. The 1990s PARC collaboration is supported by secondary and archival sources; check original Malloy/Marshall papers if making stronger claims at publication.

**Sova:** Source README calls the project alpha and describes four languages sharing a Rust VM, MIDI/OSC, Ableton Link and multiplayer. AGPL-3.0 is explicitly stated. No local build, timing measurement or audio test.

**orangu:** The current 1.4.0 release, announced 29 September 2026, adds image generation/editing, performance work, Git workflow commands, Prometheus metrics and Windows fixes. The 1.3.0 release added a model training/quantisation binary. Both release descriptions and the repository identify a local Rust stack; no local run or audit was performed. The same-seed deterministic claim is upstream only. Repository licence GPL-3.0. No local run, security audit, telemetry check or model-quality assessment.

**Mathematics Atlas:** The live site was inspected 26 October 2026 and displayed a version-4 evidence view and an inability to load the full upstream catalogue. The source README describes a version-5 update. OpenAI's current repository lists 719 manuscripts in 372 families and its dated history documents three withdrawals after a sign error. The public OpenAI mathematics collection began with 722 manuscripts on 6 October; three withdrawals leave 719 in the current source record. The atlas distinguishes source claims, Lean linkage, independent review and community acceptance. Do not treat a Lean file's existence as proof that every natural-language claim is true. The atlas's own repository did not visibly expose a licence file in the inspected root; do not call the code MIT or open source without confirmation. The site is public, but that is not a licence.

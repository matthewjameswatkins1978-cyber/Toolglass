# Toolglass Receipt

Every tested article may finish with a compact receipt:

```text
TOOLGLASS RECEIPT

STATUS
PLATFORM
VERSION
TESTED DATE
TEST TYPE
KEY MEASUREMENT
LIMITATIONS
```

Rules:

- Include only real evidence.
- Mark upstream numbers as `PROJECT CLAIM`.
- Mark measurements made by Toolglass as `TOOLGLASS MEASUREMENT`.
- Keep it short and glanceable.
- Never use fake precision.
- A receipt is an editorial record, not a dashboard.

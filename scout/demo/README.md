# Toolglass Scout demo

`toolglass-scout-demo.mp4` is a short slide/screen-recording-style demonstration
of the real `python -m toolglass_scout --demo` run. The terminal slide is generated
from the command output, not a mockup. It shows one candidate reaching human review,
one duplicate rejected by history, and one evidence-free candidate rejected before
drafting.

The deck covers the problem, audience, why it matters, the Strands/AWS boundary and
the human decision surface. It is intentionally silent and text-led; the hackathon
rules permit slides and screen recordings without an on-camera presenter.
